## ¿Qué es este repositorio?

Un recurso centralizado en español que documenta, explica y demuestra las capacidades de **Claude AI** (Anthropic) con enfoque práctico para profesionales de datos e inteligencia artificial.

Cada sección incluye: qué es, cómo funciona, para qué sirve, ejemplos reales y la ventaja competitiva que aporta.

## 🚀 ¿Por dónde empiezo?

**Si eres Data Scientist:**
Empieza por [Excel + K-means](guides/05-excel-kmeans.md) → [Deep Research](guides/03-deep-research.md) → [Artefactos](guides/07-artifacts.md)

**Si eres Desarrollador IA:**
Empieza por [Claude Code](guides/13-claude-code.md) → [Conectores MCP](guides/11-mcp-connectors.md) → [Skills Personalizadas](guides/12-custom-skills.md)
