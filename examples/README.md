# 📂 Ejemplos Prácticos

Esta carpeta contiene ejemplos listos para usar organizados por tipo:

| Carpeta | Contenido |
|---------|-----------|
| `prompts/` | Prompts optimizados y probados para cada feature de Claude |
| `notebooks/` | Jupyter notebooks con análisis completos y reproducibles |
| `workflows/` | Flujos de trabajo para Proyectos de Claude (system prompts + contexto) |
| `skills/` | Skills personalizadas con SKILL.md listas para importar |

## Cómo usar estos ejemplos

**Prompts**: copia el prompt, adáptalo a tu caso y úsalo en Claude.ai directamente.

**Notebooks**: descarga el .ipynb y ábrelo en Jupyter, o sube el archivo a Claude y pide que lo ejecute con tus datos.

**Workflows**: crea un Proyecto en Claude.ai y copia las instrucciones del sistema y archivos de contexto sugeridos.

**Skills**: si tienes acceso a la funcionalidad de skills de Claude, copia la carpeta de la skill al directorio correspondiente.
