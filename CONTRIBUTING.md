# Contribuir a Claude AI Toolkit

¡Gracias por tu interés en contribuir! Este es un proyecto comunitario y toda ayuda es bienvenida.

## ¿Cómo puedo contribuir?

### Reportar errores o sugerir mejoras
1. Abre un [Issue](../../issues) describiendo el problema o sugerencia.
2. Usa las etiquetas: `bug`, `mejora`, `nueva-guia`, `ejemplo`.

### Agregar contenido
1. Haz fork del repositorio.
2. Crea una rama: `git checkout -b feature/nombre-descriptivo`
3. Realiza tus cambios siguiendo las convenciones de abajo.
4. Haz commit: `git commit -m "Agrega: descripción breve del cambio"`
5. Push: `git push origin feature/nombre-descriptivo`
6. Abre un Pull Request describiendo tus cambios.

## Convenciones

### Guías (guides/)
- Formato Markdown con la estructura estándar: Qué es, Cómo se activa, Cómo funciona, Para qué se utiliza, Ventaja competitiva, Ejemplo rápido.
- Lenguaje claro y directo, en español.
- Incluir al menos un ejemplo práctico con código o prompt.
- Incluir links de navegación al final (anterior/siguiente).

### Ejemplos (examples/)
- Prompts: incluir contexto de uso y resultado esperado.
- Notebooks: ejecutables de principio a fin con datos sintéticos (no depender de archivos externos).
- Workflows: documentar instrucciones del sistema completas y listas para copiar.
- Skills: seguir la estructura SKILL.md con metadata yaml.

### Estilo
- Español neutro (evitar regionalismos cuando sea posible).
- Código en inglés (variables, funciones), comentarios en español.
- Sin emojis en el cuerpo del texto técnico (solo en títulos del README si aplica).

## Código de Conducta

Sé respetuoso, constructivo y colaborativo. Este es un espacio de aprendizaje.
